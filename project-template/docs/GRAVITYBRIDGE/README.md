# GravityBridge Project Coordination Memory

This directory is project-owned durable coordination memory for Codex × GravityBridge × Antigravity.

It is intentionally lightweight.

Use it to recover facts across fresh Codex sessions without relying on chat memory.

Files:

- `PROJECT_PROFILE.md` — stable project coordinates, stack, contracts and validation commands.
- `CURRENT_STATE.md` — factual current engineering state.
- `SESSION_HANDOFF.md` — latest recovery-oriented session handoff.
- `DECISION_LOG.md` — durable material decisions.
- `TASK_LEDGER.md` — material GravityBridge/Codex task state.

Do not store secrets or hidden chain-of-thought here.

Detailed worker execution evidence remains in GravityBridge runtime storage.
